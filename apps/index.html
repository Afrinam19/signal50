Built in a day, in the open

Each app is a single HTML file written with Antigravity. The commit history is the build log; the source link on each page goes straight to it.

Evidence first

Before anything renders, every number in the draft is checked against your pasted source. Matches are underlined green, misses are flagged red, open questions are amber.

A person signs off

Downloads stay disabled until the review box is ticked. The agent drafts; the human owns what leaves the building.
